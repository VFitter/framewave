# Social assets

- `framewave-social-preview.png` — 1280×640 repository social-preview image, kept below GitHub's 1 MB upload limit.
- `framewave-logo-reveal.mp4` — four-second, 1280×720 H.264 export generated by Framewave's browser export pipeline.
- `framewave-logo-reveal.gif` — lightweight 800×450 README preview derived from the MP4 export.

To reproduce the animation, start the example server and run the export helper from another terminal:

```bash
npm run dev --prefix examples -- --host 127.0.0.1
node scripts/export-logo-demo.mjs
```

The export helper accepts an optional output path and `FRAMEWAVE_DEMO_URL` override. The GIF is a distribution derivative; the MP4 is the primary animation artifact.
